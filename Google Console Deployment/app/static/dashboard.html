About this lab

rules only Not a machine-learning model. No training, no warmup, no neural net. Each 15-minute candle is scored with the rules below.

Live paper trading uses the histogram value and colour from the webhook (TradingView / Apps Script). AWS does not recompute hist from close. The X-Trend gate is ON with buffer 0.00, so any candle the line passes through is skipped. Heikin Ashi candle colour does not gate anything. The Trading view tab draws live candles from the first ingested bar.

1. Histogram (live)

Live: use the hist value and histcolor from the webhook. Do not recompute from close. green : colour green, or hist ≥ +10 if colour is missing orange : colour orange, or −10 < hist < +10 red : colour red, or hist ≤ −10

2. Entries and adds

  • Amber must appear first. Then one primary per colour run; after that only SUPP until the next amber. At most one new entry (primary or SUPP) per bar — multiple EXIT labels on one bar mean older lots closed, not multiple opens.
  • Green — on the next candle, buy when it crosses the previous candle's body (max of previous open/close). Example: previous open 4000, close 4003, wick 4005 — crossing 4003 is the buy. The 4005 wick is ignored.
  • Red — sell when the next candle crosses the previous body low.
  • Primary: previous-body cross + X-Trend clear. SUPP: only break the raw wick of the last trade candle (XT check optional, off by default). Fill SUPP at that raw wick. The Trading view paints raw MT5 candles by default so the arrow P/L matches the bar you see — Heikin Ashi bodies are signal-only and can look much taller than the real move.
  • Stop trails on the entry bar too. The entry bar is not stop-tested (the wick that filled the trade must not kill it), but its close still trails the stop. Without that the stop stays at entry ± TSL and the next bar closes the trade for −(TSL + slippage) − spread even in a strong trend.
  • Amber is the only colour event that flattens and resets the run.
  • HA candle colour never blocks an entry and never forces an exit. A red HA bar inside a green-hist run is held.
  • The arrow is drawn on the candle that made the cross. Fill is the previous body (4003), or this open on a far-side gap. The wick (4005) is never the fill.
  • Lot 0.01 (2× in best hours), leverage 1:100. Worst hours are skipped. Add blocked under about 75% margin.

3. X-Trend gate (ON, buffer 0.00)

Primary: the whole candle, wick included, must sit clear of the X-Trend line. A near-miss inside the buffer counts as touching. SUPP defaults to ignoring X-Trend and only needs a wick break of the last trade candle — switch X-Trend gate (SUPP) to ON in Testing to apply the same clearance rule to supplementary entries (live: XTREND_GATE_SUPP).

Buy only if low > X-Trend + buffer (whole candle above the band) Sell only if high < X-Trend − buffer (whole candle below the band) Otherwise no entry — the bar is counted in "XT skips"

Buffer 0.00 rejects every touching candle and nothing else. A larger buffer also rejects candles that are genuinely clear but sitting close to the line, which costs valid trades — on the full file, 0.50 gave up about $960 against 0.00. Both the gate and the buffer are editable in Backtesting → Testing.

4. Stop

  • Each candle has its own stop: after that candle closes, buy SL = max(old, close − 0.25), sell SL = min(old, close + 0.25). Start at −0.25 from fill; if price goes up the stop steps up with it.
  • The entry candle is not stopped against its own wick. That trail becomes live on the next candle.
  • Opposite HA does not freeze the trail. Hit: buy if candle low ≤ stop; sell if candle high ≥ stop. No take-profit.

5. What is not used

  • X-Trend is a clearance gate only. It is not an entry signal by itself.
  • No HA-colour gate and no close-confirm on the break.
  • No warmup of a “model” for live hist — colour and value come from the feed.
  • Spread in backtesting is the broker bid–ask on each fill, not a charge every candle.

Orange : −10 < hist < +10 → no trade · flatten if in a position
Red    : hist ≤ −10     → sell / add when this candle crosses the previous body low

X-Trend source (Testing / Process):
  SuperTrend HA 6/0.8  OR  KJ GagaTrend on HA  OR  CSV column

  candle must NOT touch the X-Trend line (buffer adds extra clearance)
  Buy  : low  > X-Trend + buffer
  Sell : high < X-Trend − buffer

         (buy SL = price − 0.25 · sell SL = price + 0.25). No take-profit.
Lot    : 0.01   ·   Leverage : 1:100   ·   Block add if margin level would fall under ~75%

X-Trend check

        

          using X-Trend check
          Recalculates X-Trend from OHLC with GagaTrend, scores it against the file’s X-Trend column, then applies the QQE gate for LONG / SHORT.
        

        
Upload a CSV with time, open, high, low, close, and X-Trend. Histogram is computed here from close (file Plot/hist ignored).

        

          
          
          
          
          
          
        

        

      

      

        
Formulas used

        
1. X-Trend (GagaTrend) — OHLC only, open unused

        
Swing high = highest high of last 2 bars
Swing low  = lowest low of last 3 bars
Smooth     = SMA(high, 2) · SMA(low, 2 / 3 / 4) · ATR(14)

Bull (trend = 0): line = up, ratchet up only from the tracked swing-low
  Flip to bear when SMA(high,2) < swing-low AND close < previous low

Bear (trend = 1): line = down, ratchet down only from the tracked swing-high
  Flip to bull when SMA(low,3 or 4) > swing-high
                 (or early: SMA(low,2) already above and SMA(low,3) within 0.025×ATR)
                 AND close > previous high

X-Trend = (trend == 0) ? up : down
Correct if |formula − file X-Trend| ≤ 0.01 points

        
2. Histogram (same as AWS / PDF)

        
hist = EMA(WilderRSI(close, 3), 5) − 50
green  if hist > +10
red    if hist < −10
orange otherwise

        
3. Live / backtest trades — candle must not touch X-Trend

        
using X-Trend check to make the trade (live always ON)

Buy  : low  > X-Trend + buffer
Sell : high < X-Trend − buffer
Buffer 0.00 (default) → blocks exactly the candles the line runs through
Raising the buffer also blocks clear-but-close candles, costing trades
Backtesting: gate and buffer are both editable in Testing

        
4. LONG / SHORT labels (GagawedsQQE)

        
Histogram turns green → arm long  (orange disarms both)
Histogram turns red   → arm short (orange disarms both)
Heikin Ashi candle must sit fully above the X-Trend for long  (HA low  > line)
Fully below for short (HA high < line)
Then print LONG / SHORT once and disarm

A long needs: green hist (after a green turn) AND Heikin Ashi entirely above X-Trend.
Short is the mirror.
